# Behavioral-Finance-Factor

一个面向 A 股的行为金融因子研究与复现项目。项目覆盖投资者注意力、羊群效应、参考点、前景理论、分析师锚定和注意力溢出等机制，提供因子说明、原始值批量计算脚本、Notebook 研究过程与米筐回测报告。

> 本目录用于研究与学习，不构成投资建议。因子的经济解释不等于可交易结论，所有信号均须在明确的股票池、可得数据时点和交易成本假设下重新检验。

### 项目边界与实现状态

这是一个研究与复现项目，而不是已发布的 Python 包。当前核心可计算范围由 `factor_data/manifest.json` 定义：其中包含 22 个原始因子批量计算脚本，统一输出为日期 × 股票的 CSV 宽表。Notebook、公式说明和回测报告用于解释与验证这些原始因子，不应被误解为可直接实盘部署的策略。

研究文档中的状态标记以 `行为金融因子.md` 为准：

| 标记 | 含义 | 使用时仍需完成的工作 |
| --- | --- | --- |
| ✅ | 已完成数据获取与有效性检查 | 用自己的股票池、样本期和数据权限复核 |
| ⭐ | 已有因子回测记录 | 复现回测并加入交易成本、调仓和样本外检验 |
| ❌ | 目前没有可复现实现 | 不应视为可运行因子 |
| 🚨 / ❓ | 依赖受限数据、数据稀疏或存在口径限制 | 先确认接口、可得时点和样本覆盖度 |

因子值、状态标记和历史回测都不代表未来收益或可交易性；它们只说明项目当前的研究与实现范围。

建议按目标选择入口：

1. **理解结果**：先看 [行为金融因子回测总结.md](行为金融因子回测总结.md)，再进入[完整回测报告](行为因子回测结果/行为金融因子与米筐回测.md)。
2. **理解理论与口径**：阅读 [行为金融因子_通俗解读与故事版.md](行为金融因子_通俗解读与故事版.md)、[行为金融因子.md](行为金融因子.md) 与 [股票数据处理总结.md](股票数据处理总结.md)。
3. **批量生成原始因子**：阅读 [factor_data/README.md](factor_data/README.md)，从 `manifest.json` 选择脚本执行。
4. **查看研究过程**：打开对应主题的 Notebook；它们适合逐单元检查数据、公式和中间结果。

## 快速开始

批量计算脚本以 Python、`numpy`、`pandas` 与米筐 `rqdatac` 为基础。读取本地缓存时需要 `pyarrow`；基金持仓相关代码还依赖米筐的基金数据能力。Notebook 内曾使用 `rqdatac==3.4.2` 与 `rqdatac-fund==1.0.44`，但若你所在的米筐环境有统一版本，应以该环境的兼容性要求为准。

```bash
python -m pip install numpy pandas pyarrow "rqdatac==3.4.2" "rqdatac-fund==1.0.44"
```

运行前需要在当前环境完成米筐数据服务的初始化与授权；不要把账号、密码、令牌或本地数据路径写入并提交到 Notebook。先以短样本、少量证券验证数据权限、字段名、输出形状和运行时间，再扩展到全 A 股与长样本。

例如，以下命令生成 ABNRETD 的原始宽表；`--output-dir` 应指向项目外部或被忽略的结果目录：

```bash
python "factor_data/最大异常日收益率（ABNRETD）.py" --start-date 2020-01-01 --end-date 2025-12-31 --data-dir factor_data/data --output-dir outputs
```

输出 CSV 的索引列固定为 `datetime`，其余列为 `order_book_id`；值为相应脚本的原始因子值。默认计算区间为 2019-01-01 至 2026-08-31，完整的脚本—字段映射见 `factor_data/manifest.json`。

### 本地数据缓存

部分脚本除了日频行情接口外，还依赖从米筐导出的本地缓存。将数据解压到 `factor_data/data/` 后，目录应包含：

```text
factor_data/data/
├── fund_holdings/                    # 基金持仓明细
├── get_comp_indicators/              # 一致预期指标
└── get_instrument_industry_monthly/  # 月度行业分类
```

基金类因子、CAF_EP 及行业相关因子会使用这些本地文件；其余日频行情因子主要通过 `rqdatac` 获取数据。该目录已被 `.gitignore` 排除，避免将授权数据、超大文件或个人数据缓存提交至仓库。

## 已实现的计算主题

`factor_data/` 将每个可计算因子拆分为独立脚本，以便只生成所需的原始值。各脚本共享 `_factor_io.py` 的命令行参数、宽表格式和保存逻辑；下表按研究主题归类，不替代 `manifest.json` 中的精确脚本与字段清单。

| 主题 | 代表性原始因子 | 所刻画的行为机制 |
| --- | --- | --- |
| 异常收益与交易注意力 | ABNRETD、ABNRETAVG、ABNVOLD、ABNVOLAVG、ATTN、TURNAVG | 极端收益、异常成交量和交易活跃度带来的有限注意力 |
| 羊群与机构交易 | 三类 CSAD、LSV、SLSV | 市场或相似股票群体在极端行情中的收益趋同性，以及基金抱团行为 |
| 参考点与前景理论 | CGO、TK、PB-TK | 浮盈浮亏、损失厌恶与风险偏好的状态依赖 |
| 预期偏差与注意力溢出 | CAF_EP、异常收益 SPILL、换手率 SPILL | 分析师锚定、行业内热点扩散及注意力传导 |
| 回归型注意力捕捉 | 涨跌停、行业异常收益、行业波动、市场成交额、行业换手率 | 个股收益对市场关注代理变量的敏感度 |

CSSD 与基础 CSAD 等市场状态模型仍保留在研究文档和 Notebook 中；是否将其作为独立批量输出，取决于相应脚本是否列在 `manifest.json`。

## 推荐研究流程

1. **固定研究设定**：记录股票池、样本起止日、调仓频率、复权方式、行业分类版本和缺失值规则。
2. **小样本通跑**：先对少量证券和短区间运行一个入口，核验数据权限、索引名称、列名及时间对齐。
3. **保存原始因子**：保留未处理的输出，并另行记录去极值、标准化、中性化等后处理参数，避免覆盖原始结果。
4. **按可得时点回测**：用信号形成日之后的收益作为标签；对财务、预期和持仓数据加入披露滞后，避免前视偏差。
5. **检验可交易性**：除分组收益外，同时报告覆盖率、换手、涨跌停约束、停牌、成本、容量和样本外表现。

Notebook 适合研究和调试，但其中的单元可能依赖此前定义的辅助函数；若目标只是批量生成原始值，优先使用 `factor_data/` 中对应的独立脚本。

## 典型因子：ABNRETD

最大异常日收益率（ABNRETD）衡量一段窗口内，个股日收益与市场日收益的最大绝对偏离：

$$
\mathrm{ABNRETD}_{i,T} =
\max_{t=T-m+1}^{T}\left|r_{i,t}-\bar r_t\right|
$$

其中 $r_{i,t}$ 是个股日收益，$\bar r_t$ 是市场日收益，$m$ 通常取一个月左右的交易日窗口。因子值越高，表示个股曾出现更显著的异常日波动，常被视为投资者注意力的代理变量。

`factor_data/最大异常日收益率（ABNRETD）.py` 使用两步计算：先根据全市场有效股票的日收益构造市场等权收益，再按股票计算滚动窗口内的最大绝对异常收益。默认窗口为 20 个交易日；脚本将结果保存为 `datetime × order_book_id` 的 CSV 宽表。

ABNRETD 本身不规定做多或做空方向。若研究“高关注度导致短期溢价、之后反转”的假设，应以未来收益、分组表现和可交易约束验证低因子组与高因子组的相对表现。

## 数据需求

不同模块从米筐读取的字段和接口并不相同：

| 数据 | 主要用途 |
| --- | --- |
| 日度收盘价、成交量、成交额、交易日历 | 收益率、异常收益、异常成交量、注意力事件 |
| 换手率 | CGO、ATTN、TURNAVG 与换手率注意力溢出 |
| 市值、账面市值比、无风险利率 | 市场 / 规模 / 价值 / 动量控制变量 |
| 行业分类 | 行业内注意力、行业波动与溢出效应 |
| 分析师一致预期 PE | CAF_EP；Notebook 中该章节标注为付费接口 |
| 基金持仓与披露日期 | LSV；Notebook 中该章节标注为付费接口 |

所有数据都应按当时可得口径使用。尤其应处理停牌、复权、上市时间、成分股历史变化和财报 / 持仓披露滞后，避免把事后数据带入信号日。

## 输出与使用方式

研究函数通常返回两层索引的 `pandas.DataFrame`：

```text
index:   (date, order_book_id)
column:  对应因子名称
```

批量计算脚本会将这类面板转换为 CSV 宽表：

```text
index:   datetime
columns: order_book_id
value:   原始因子值
```

CSSD 与基础 CSAD 一类的市场状态模型则可能返回日期索引的时间序列。将因子用于截面检验前，建议至少完成以下检查：

- 信号只使用信号日及之前能够观察到的数据；
- 同一交易日的股票池与行业归属符合历史时点；
- 剔除或单独处理停牌、涨跌停、极端复权和缺失观测；
- 对因子做必要的去极值、标准化和行业 / 市值暴露检验；
- 使用样本外时期、调仓频率、换手率和交易成本评估稳健性。

## 性能与权限提示

- 全 A 股长样本的数据下载、逐日滚动回归和行业分组会消耗较多时间与内存。
- “小型板块”CSAD 需要构造股票间相关性；股票池越大，计算量增长越快。
- 回归型注意力因子需要同时构建市场、规模、价值与动量控制变量，较适合先在短样本上验证。
- 分析师预期和基金持仓章节依赖付费或权限受限接口；无权限时，其余仅依赖行情的数据模块仍可单独研究。
